# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Deep-Learning-Projects.git
cd Deep-Learning-Projects
```

---

## 2️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

If a `requirements.txt` file is unavailable for a specific project:

```bash
pip install torch torchvision torchaudio transformers opencv-python matplotlib numpy pandas scikit-learn
```

---

# ▶️ Running a Project

Example:

```bash
cd "Project 14: CNN on CIFAR-10"
```
